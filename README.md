# Library-Management-System

This project connects Python with MongoDB and processes an image using the Pillow library.

## Requirements

Before running the project, install the necessary packages and set up MongoDB.

## Installation and Setup

### 1. Install Required Python Packages

```bash
pip install pymongo
pip install pillow
```

### 2. Set Up MongoDB

```bash
sudo systemctl start mongodb
sudo systemctl enable mongodb
```

### 3. Run the Project

```bash
python3 -m venv venv
source venv/bin/activate
python task1.py
```
